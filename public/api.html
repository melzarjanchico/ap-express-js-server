API Documentation

Interact with the Melzar API endpoints below. All paths are relative to the base URL.

Core Core Endpoints

Method Path Query Params Description
GET / - Serves this documentation page.
POST /echo - Echoes back the JSON payload sent in the request body.

SP Spotify Service

Method Path Query Params Description
GET /spotify/user - Retrieve the authenticated Spotify user profile.
GET /spotify/current_track - Get the currently playing track for the user.
GET /spotify/tracks time_range, limit, offset List top tracks for the given time range.
GET /spotify/artists time_range, limit, offset List top artists for the given time range.
GET /spotify/wrapped/:year - Fetch the Spotify Wrapped playlist for a given year.

ST Steam Service

Method Path Query Params Description
GET /steam/owned_games - List games owned by the user.
GET /steam/current_game - Get the currently played game.

LB Letterboxd Service

Method Path Query Params Description
GET /letterboxd/recent - Retrieve recent watch entries from Letterboxd.

LF Last.fm Service

Method Path Query Params Description
GET /lastfm/recent_track limit Retrieve recent tracks listened to by the user.
GET /lastfm/top_tracks limit, period List top tracks for the given period.
GET /lastfm/top_artists limit, period List top artists for the given period.
GET /lastfm/top_albums limit, period List top albums for the given period.

VS VS Code Presence Service

Method Path Query Params Description
GET /vscode/presence - Retrieve the latest VS Code presence (status, project, workspace, file, language, logo). Returns status "offline" when no presence has been set.
